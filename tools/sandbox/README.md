# DEBUG 房间编辑器

这是一个给 FPGA 游戏 demo 使用的房间布局工具。房间固定为 **1280×720**，使用 **40×23** 个 32 像素网格，导出的文本可以交给 C 侧的房间生成逻辑。

## 启动

在仓库根目录运行：

```text
uv run tools/sandbox/serve.py
```

浏览器打开 `http://127.0.0.1:8765/tools/sandbox/index.html`。

通过 `serve.py` 打开时，可以把地图保存到 `tools/sandbox/output/`，也可以从该目录读取已有地图。页面会用 `localStorage` 自动保存当前编辑内容。

## 编辑方式

- 左键绘制，右键擦除。
- `R` 循环角落方向，`1` 到 `4` 直接选择 `C/X/Y/Z`。
- `B` 选择地板，`W` 选择木墙，`D` 选择门，`E` 选择空白。
- `Ctrl+Z` 撤销，`0` 适应窗口，`+/-` 调整缩放。
- 门用一个 `D` 字符表示，绘制时占用当前格和下一格，共 1×2。

## 导出字符

地图文本固定为 23 行，每行 40 个字符：

| 字符 | 含义 |
| --- | --- |
| `.` | 空白 |
| `B` | 基岩地板 |
| `W` | 木墙 |
| `D` | 门，占 1×2 |
| `C` / `X` / `Y` / `Z` | 角落四个镜像方向 |

素材从 `res/pic/base/background/` 加载。角落当前使用 `background_corner_wood.png`，四个方向由画布镜像得到，和 RTL 的 `FLIP_X/FLIP_Y` 约定一致。
