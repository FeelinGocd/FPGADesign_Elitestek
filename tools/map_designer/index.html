对象笔刷

角落翻转

C 原样 / X 水平 / Y 垂直 / Z 双向，对应 RTL 的 FLIP_X / FLIP_Y。

旋转 / 门方向

墙和地板按这个角度旋转；门的方向是 N/E/S/W。
