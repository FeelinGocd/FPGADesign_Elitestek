## 下次开工先做这三件

### 1. 增加弹幕类型
- 现在只有 `MOTION_LINE / SINE / ACCEL / SPIRAL / HOME` 五种弹道，
  图案表 `g_boss_patterns[]` 里的形状靠 count/step/twin/spin 拼
- 想加"会拐弯/会分裂/会停下再加速"这类新弹道：
  - 弹道：`game_bullet.c` 的 `bullet_move()` 加一个 `MOTION_xxx`
  - 贴图：新弹种涉及新素材 ⇒ `res/pic/` 加图 ⇒ `uv run res/func/pic2pram.py`
    ⇒ **必须重新综合**（素材是 BRAM 初值）
  - 若只是参数不同（更快/更大/更密），**不用新素材**，改 `g_boss_patterns[]` 即可

### 2. 绘制背景
- 现在地板是 4×4 的 32×32 地砖平铺（`game_world.c` 的 `game_blit_tile`）
- 候选方向：整屏一张背景图（1280×720 太大：PRAM 只 32768 词 ≈ 256KB，
  现在用了约 45%，塞不下一整屏）⇒ 要么分块、要么用 DDR3 直接 blit
- 参考：`docs/spec/软件_驱动与API.md` 的 blit / fillRect / 命令表

### 3. 特效
- 现在只有：受击闪红（`combineTintRect`）、护盾闪白、拾取字幕
- 候选：子弹命中火花、Boss 击破爆炸、拾取时的光效
- 高效做法：**颜色合成 `tone=2 加光` + 几帧淡出**，不必新素材
- 新素材的话同第 1 条：`pic2pram.py` + 重新综合
