# docs/spec — 设计规格文档

| 文件 | 内容 |
|---|---|
| `01_系统架构设计.md` | 总体分层（L1 软件 / L2 总线 / L3 加速 / L4 存储 / L5 显示）与数据流 |
| `02_寄存器映射.md` | BitBlt 引擎 / 视频 / SoC 寄存器地址与位定义（软硬件共用） |
| `03_接口契约.md` | AXI4 / Wishbone 约定、突发长度、数据位宽、命令格式 |
| `04_地址空间规划.md` | DDR3 分区：Framebuffer A/B、贴图区、命令队列、堆栈 |
