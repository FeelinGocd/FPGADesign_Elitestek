> **2026-09-16 主要修订**
> 1. 帧缓冲像素格式：XRGB8888（4 字节）→ **RGB888（3 字节）**，相关尺寸与带宽全部重算
> 2. 新增：存储分层（BRAM/DDR/Flash）、带宽预算、索引色
> 3. 修正：**AXI ID 截断不会导致故障**（MUX 靠信息 FIFO 记账，不靠 ID 路由）；全链路统一 **ID = 0**
> 4. 修正：`Axi_Mux` **只有轮询 / S0 固定优先级两档**，没有"显示 > 加速器 > CPU"三级优先与老化兜底
