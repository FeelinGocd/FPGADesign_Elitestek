# docs/spec — 设计规格文档

本目录是团队自建规格，也是软硬件并行开发的**接口契约**。
**只放现状**：过时的机制不留在正文里（历史进各文件的版本表，旧稿进 `_归档/`）。

## 文件地图（7 份 + 1 份临时）

| 文件 | 内容 | 什么时候看 |

## 维护规则

| 规则 | 说明 |
|---|---|
| **接口只有一处唯一定稿** | 命令位分配 / 功能号 / `flags` 只在 `硬件_加速器.md` §1；改它要同时改 `DDRSource` / `PaletteSource` / `Compositor` 三处解码 |
| **数字必须能追到出处** | 实测数字一律进 `实测数据.md` 并标**日期 + 来源**（哪次综合 / 哪个 TB / 哪天上板）；设计期估算与实测分开写 |
| **过时的内容不要留在正文** | 机制变了就把旧机制的描述删掉，历史写进该文件的版本表 |
| **改了 RTL 就更新对应那节** | 尤其是"坑"和"纪律"两节：它们都是从真实故障里长出来的 |
| **`_归档/` 不要改** | 需要引用旧结论时，把结论搬进新文件并标注 |
